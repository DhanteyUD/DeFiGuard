## Project Summary

**DeFiGuard** is an AI-powered multi-agent risk management system that protects DeFi users from rug pulls, honeypots, and scam tokens across **Solana + 12 EVM chains**.

## Key Features

🛡️ **Real-time Portfolio Monitoring** - Tracks wallets across 13 chains
🧠 **AI Risk Analysis** - SingularityNET MeTTa knowledge graphs
◎ **Full Solana Support** - SPL tokens, mint authority checks, RugCheck integration
🚨 **Fraud Detection** - Honeypot detection, holder concentration analysis
💬 **Natural Language Interface** - Chat-based interaction via ASI:One

## Solana-Specific Capabilities

- Native SOL + all SPL token tracking
- Mint authority verification (rug pull prevention)
- Freeze authority detection (token freeze risk)
- Integration with RugCheck.xyz API
- Jupiter token list verification
- Holder distribution analysis

## Why Audit?

DeFiGuard makes security recommendations to users. A vulnerability could:
- Give false safety signals for scam tokens
- Miss critical fraud indicators
- Compromise user trust

## Audit Scope

- **~3,300 lines of code**
- Solana integration module (critical)
- Multi-agent communication layer
- MeTTa knowledge base integrity
